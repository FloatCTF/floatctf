# Triage 标签

skill 用五个固定角色说话；下表是本仓库的实际标签字符串（已全部创建在 GitHub 上）。

| 角色 | 本仓库标签 | 含义 |
|---|---|---|
| needs-triage | `needs-triage` | 维护者需要先评估 |
| needs-info | `needs-info` | 等报告者补充信息 |
| ready-for-agent | `ready-for-agent` | 规格齐全，可直接交给 agent |
| ready-for-human | `ready-for-human` | 需要人来实现 |
| wontfix | `wontfix` | 不做 |

skill 说「打 AFK 就绪标签」时，用右列对应字符串。
